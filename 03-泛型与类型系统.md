# 3. 泛型与类型系统

## 3.1 类型擦除

Java泛型是**编译时特性**，运行时类型信息被擦除：

```java
public class GenericErasure {
    public static void main(String[] args) {
        List<String> stringList = new ArrayList<>();
        List<Integer> integerList = new ArrayList<>();
        
        // 运行时都是同一个Class对象
        System.out.println(stringList.getClass() == integerList.getClass()); // true
        
        // 无法获取泛型类型参数
        // stringList.getClass() 无法知道它是 List<String>
    }
}
```

**类型擦除规则**：
- 无界类型参数 `<T>` → `Object`
- 上界 `<T extends Number>` → `Number`
- 下界 `<T super Integer>` → `Integer`

```java
// 编译后
// <T> → Object
// <T extends Number> → Number
// <T extends Comparable<T>> → Comparable

public <T> T first(List<T> list) { ... }
// 擦除为：public Object first(List list) { ... }

public <T extends Comparable<T>> T max(T a, T b) { ... }
// 擦除为：public Comparable max(Comparable a, Comparable b) { ... }
```

## 3.2 通配符

### 3.2.1 三种通配符

```java
public class WildcardExample {
    // 上界通配符：? extends T
    // 只能读取，不能写入（除了null）
    public static void readOnly(List<? extends Number> list) {
        Number n = list.get(0); // OK
        // list.add(1);         // Compile Error
    }
    
    // 下界通配符：? super T
    // 可以写入T及其子类，读取只能得到Object
    public static void writeOnly(List<? super Integer> list) {
        list.add(1);           // OK
        list.add(1.0);        // Compile Error
        Object obj = list.get(0); // OK，只能得到Object
    }
    
    // 任意通配符：?
    // 等同于? extends Object
    public static void unknown(List<?> list) {
        Object obj = list.get(0);
    }
}
```

### 3.2.2 PECS 原则

> **P**roducer **E**xtends, **C**onsumer **S**uper

```java
// 如果要从集合中读取数据（生产者），使用 extends
List<? extends Readable> source = ...;

// 如果要往集合中写入数据（消费者），使用 super
List<? super Writable> target = ...;
```

## 3.3 泛型与反射

```java
public class GenericReflection {
    public static void main(String[] args) throws Exception {
        // 通过反射获取泛型信息
        Method method = MyClass.class.getMethod("process");
        Type returnType = method.getGenericReturnType();
        
        if (returnType instanceof ParameterizedType) {
            ParameterizedType paramType = (ParameterizedType) returnType;
            Type[] typeArgs = paramType.getActualTypeArguments();
            System.out.println("返回值泛型参数: " + typeArgs[0]); // class java.lang.String
        }
        
        // 父类泛型信息
        Type superClass = MySubClass.class.getGenericSuperclass();
    }
    
    class MyClass {
        public List<String> process() { return null; }
    }
    
    class MySubClass extends ArrayList<String> { }
}
```

## 3.4 桥方法

类型擦除可能导致方法签名冲突，编译器自动生成**桥方法**：

```java
public class BridgeMethod {
    // 原始类型
    public static class Node<T> {
        public T getData() { ... }
        public void setData(T data) { ... }
    }
    
    // 子类指定具体类型
    public static class StringNode extends Node<String> {
        // 编译器生成桥方法：
        // public Object getData() { return getData(); }
        // public void setData(Object data) { setData((String) data); }
    }
}
```
