# 4. 反射与注解

## 4.1 反射 API

### 4.1.1 获取 Class 对象

```java
public class ReflectionBasic {
    public static void main(String[] args) throws Exception {
        // 方式1：通过类名
        Class<?> clazz = Class.forName("com.example.User");
        
        // 方式2：通过对象
        User user = new User();
        Class<?> clazz2 = user.getClass();
        
        // 方式3：通过.class
        Class<User> clazz3 = User.class;
    }
}
```

### 4.1.2 反射操作

```java
public class ReflectionOperation {
    public static void main(String[] args) throws Exception {
        Class<User> clazz = User.class;
        
        // 获取构造器并创建实例
        Constructor<User> constructor = clazz.getDeclaredConstructor(String.class, int.class);
        constructor.setAccessible(true);
        User user = constructor.newInstance("Alice", 25);
        
        // 获取字段并赋值
        Field nameField = clazz.getDeclaredField("name");
        nameField.setAccessible(true);
        nameField.set(user, "Bob");
        
        // 获取方法并调用
        Method greetMethod = clazz.getDeclaredMethod("greet", String.class);
        greetMethod.setAccessible(true);
        String result = (String) greetMethod.invoke(user, "World");
        
        // 获取所有注解
        Annotation[] annotations = clazz.getAnnotations();
    }
}
```

### 4.1.3 反射性能优化

```java
public class ReflectionPerf {
    public static void main(String[] args) throws Exception {
        Method method = User.class.getMethod("greet", String.class);
        
        // 优化1：关闭安全检查
        method.setAccessible(true);
        
        // 优化2：使用 MethodHandle（Java 7+）
        MethodHandles.Lookup lookup = MethodHandles.lookup();
        MethodHandle mh = lookup.unreflect(method);
        String result = (String) mh.invoke(user, "arg");
        
        // 优化3：使用字节码生成（MethodHandleProxies）
        MyInterface proxy = (MyInterface) MethodHandleProxies.asInterfaceInstance(
            MyInterface.class, mh
        );
    }
}
```

## 4.2 注解

### 4.2.1 自定义注解

```java
// 元注解
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface MyAnnotation {
    String value() default "";
    int priority() default 0;
    String[] tags() default {};
}
```

**Retention 策略**：
| 策略 | 说明 |
|------|------|
| `SOURCE` | 仅源码保留，编译时丢弃 |
| `CLASS` | 编译后保留在.class中，运行时丢弃 |
| `RUNTIME` | 运行时保留，可通过反射获取 |

### 4.2.2 注解处理

```java
// 编译时注解处理器
@SupportedAnnotationTypes("com.example.MyAnnotation")
@SupportedSourceVersion(SourceVersion.RELEASE_11)
public class MyAnnotationProcessor extends AbstractProcessor {
    @Override
    public boolean process(Set<? extends TypeElement> annotations, RoundEnvironment roundEnv) {
        for (Element element : roundEnv.getElementsAnnotatedWith(MyAnnotation.class)) {
            MyAnnotation annotation = element.getAnnotation(MyAnnotation.class);
            // 处理注解
        }
        return true;
    }
}

// 运行时注解获取
public class RuntimeAnnotation {
    public static void main(String[] args) {
        MyAnnotation annotation = User.class.getAnnotation(MyAnnotation.class);
        if (annotation != null) {
            System.out.println("value: " + annotation.value());
            System.out.println("priority: " + annotation.priority());
        }
    }
}
```

## 4.3 动态代理

### 4.3.1 JDK 动态代理

```java
public class JdkProxy implements InvocationHandler {
    private final Object target;
    
    public JdkProxy(Object target) {
        this.target = target;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        System.out.println("Before: " + method.getName());
        Object result = method.invoke(target, args);
        System.out.println("After: " + method.getName());
        return result;
    }
    
    // 创建代理
    @SuppressWarnings("unchecked")
    public static <T> T createProxy(T target, Class<T> interfaceType) {
        return (T) Proxy.newProxyInstance(
            target.getClass().getClassLoader(),
            new Class<?>[]{interfaceType},
            new JdkProxy(target)
        );
    }
}
```

**JDK 动态代理特点**：
- 只能代理**接口**
- 基于反射实现
- 代理类命名：`$Proxy0`
- 性能较差

### 4.3.2 CGLIB 动态代理

```java
// 使用CGLIB代理普通类（不需要接口）
public class CglibProxy implements MethodInterceptor {
    public <T> T createProxy(Class<T> targetClass) {
        Enhancer enhancer = new Enhancer();
        enhancer.setSuperclass(targetClass);
        enhancer.setCallback(this);
        enhancer.setClassLoader(targetClass.getClassLoader());
        return (T) enhancer.create();
    }
    
    @Override
    public Object intercept(Object obj, Method method, Object[] args, MethodProxy proxy) throws Throwable {
        System.out.println("Before: " + method.getName());
        Object result = proxy.invokeSuper(obj, args); // 调用父类方法
        System.out.println("After: " + method.getName());
        return result;
    }
}
```

### 4.3.3 两种代理对比

| 特性 | JDK 动态代理 | CGLIB 代理 |
|------|-------------|------------|
| 代理对象 | 接口 | 普通类 |
| 实现方式 | 反射 | 字节码生成 |
| 性能 | 较差 | 较好 |
| 依赖 | JDK自带 | CGLIB库 |
