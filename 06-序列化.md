# 6. 序列化

## 6.1 Java 原生序列化

### 6.1.1 实现 Serializable

```java
public class User implements Serializable {
    private static final long serialVersionUID = 1L;
    
    private String name;
    private int age;
    private transient String password; // transient字段不参与序列化
    
    // 静态字段不会被序列化
    private static String company = "Tech Corp";
    
    // 自定义序列化
    private void writeObject(ObjectOutputStream out) throws IOException {
        out.defaultWriteObject();
        // 自定义写入
        out.writeUTF(encrypt(password));
    }
    
    private void readObject(ObjectInputStream in) throws IOException, ClassNotFoundException {
        in.defaultReadObject();
        // 自定义读取
        password = decrypt(in.readUTF());
    }
}
```

### 6.1.2 Externalizable 接口

```java
public class Order implements Externalizable {
    private String id;
    private BigDecimal amount;
    
    @Override
    public void writeExternal(ObjectOutput out) throws IOException {
        out.writeUTF(id);
        out.writeObject(amount);
    }
    
    @Override
    public void readExternal(ObjectInput in) throws IOException, ClassNotFoundException {
        id = in.readUTF();
        amount = (BigDecimal) in.readObject();
    }
}
```

**Serializable vs Externalizable**：

| 特性 | Serializable | Externalizable |
|------|-------------|----------------|
| 实现方式 | 标记接口 | 强制实现write/read |
| 性能 | 反射，较慢 | 直接方法调用，较快 |
| 控制度 | 默认序列化，transient排除 | 完全控制序列化内容 |
| 使用场景 | 通用场景 | 对性能/格式有要求 |

## 6.2 序列化注意事项

```java
public class SerializationBestPractice {
    // 1. 必须显式声明 serialVersionUID
    private static final long serialVersionUID = 1L;
    
    // 2. 避免序列化敏感数据
    // 使用 transient 或自定义 writeObject
    
    // 3. 序列化时保持类结构兼容
    // 新增字段提供默认值
    
    // 4. 单例需防止序列化破坏
    public class Singleton implements Serializable {
        private static final long serialVersionUID = 1L;
        private static final Singleton INSTANCE = new Singleton();
        
        private Singleton() {}
        
        public static Singleton getInstance() { return INSTANCE; }
        
        // 防止反序列化创建新实例
        protected Object readResolve() {
            return INSTANCE;
        }
    }
    
    // 5. 使用安全的序列化过滤
    public class SafeDeserialization {
        public static void main(String[] args) {
            // JDK 9+ 引入ObjectInputFilter
            ObjectInputFilter filter = ObjectInputFilter.Config.createFilter(
                "com.example.*;java.lang.*", null);
        }
    }
}
```
